# 海风城市冲刺 · Sea Breeze City Sprint 🌊🌆🐈

一段有起点、阶段变化与终点结算的伪 3D 城市冲刺跑酷。小猫从明亮的海边公路出发，穿过城市高架，闯入夜间灯牌街区，冲过 1000m 终点。

**在线游玩：<https://sumomo0222.github.io/coastal-city-sprint/>**

## 玩法

- **左右换道**：`←` `→` 或 `A` `D`；手机左右滑动
- **跳跃**：`↑` `W` `空格`；手机上滑或点按
- **目标**：躲避障碍、收集能量币 🪙，1000m 冲线后结算得分与评级（S/A/B/C）
- 低栏可跳过（条纹跨栏/锥桶），高箱必须换道；连续收集不碰撞可拿高评级
- 最佳成绩自动存入 localStorage

## 三段旅程

| 阶段 | 里程 | 场景 |
|---|---|---|
| 🌊 海滨公路 | 0–340m | 海面浪线、沙滩、遮阳伞、浮标、海鸥、白护栏 |
| 🌆 城市高架 | 340–680m | 天际线剪影、斜拉门塔、混凝土护栏墙、路边广告牌 |
| 🌃 夜间灯牌街区 | 680–1000m | 星空月亮、点亮窗格、霓虹竖招牌、跨街灯牌龙门、路灯光池 |
| 🏁 终点 | 1000m | FINISH 彩带横幅 + 棋盘门柱 + 彩带雨结算 |

## 伪 3D 透视（本作核心）

全场景共用**一个针孔投影** `project(x,y,z)`（消失点 VP = 屏幕中心 × 地平线）：

- 路面、车道虚线、路缘线、护栏立柱与横杆、护栏墙、灯杆、广告牌、楼房、斜拉塔、龙门、障碍物、金币、终点门 —— 全部经同一投影绘制，向同一消失点收束
- 护栏由逐段立柱 + 相邻柱间横杆梯形构成，沿道路边缘向远处延伸收束，**不是横穿屏幕的水平线**
- 障碍物明确出现在某条跑道上（三车道各含中心 x），顶面/侧面同样按透视投影
- 速度线也以 VP 为端点放射

## 技术

- 纯静态单文件 `dist/index.html`（Canvas 2D，零依赖，约 60KB），桌面 + 手机触控自适应
- `?seed=<n>` 固定关卡种子（可复现）
- 验证：`.preview/verify-coastal2.mjs` 真实 Chrome 48 项断言（含护栏收束单调性、分道线收敛、障碍落道投影核对、双端触控、完赛结算），像素结构探针另验猫/太阳/月亮/终点门/三阶段天空

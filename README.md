# 海风城市冲刺 · COASTAL CITY SPRINT

打开链接即玩的轻量**伪 3D 海岸跑酷网页小游戏**：从明亮的海边公路出发，穿过城市高架，闯过夜间灯牌街区，躲开路障与货车、收集能量币，在 1000m 终点拱门冲线，争夺 S 级评价与最佳用时。

整个场景（海面与波浪、沙滩、椰子树、遮阳伞、帆船、护栏、路灯、高架天桥、霓虹广告牌、灯串、道路、终点拱门、角色、障碍、能量币）全部使用 **HTML / CSS / 内联 SVG** 程序化绘制，**零外部图片素材、零依赖、零构建**。

**在线试玩**：<https://sumomo0222.github.io/coastal-city-sprint/>

## 本地打开

方式一（最简单）：直接用浏览器打开 `dist/index.html` 即可，无需任何服务器。

方式二（可选，本地静态预览）：

```bash
cd coastal-city-runner/dist
python3 -m http.server 8080
# 浏览器访问 http://localhost:8080
```

## 操作方式

| 动作 | 桌面端 | 手机端 |
| --- | --- | --- |
| 左移 | `←` 或 `A` | 左下角 `◀` 按钮 / 屏幕左滑 |
| 右移 | `→` 或 `D` | 左下角 `▶` 按钮 / 屏幕右滑 |
| 跳跃 | `空格` / `↑` / `W` | 右下角 `▲` 按钮 / 屏幕上滑或点按 |
| 开始 / 重开 | `回车` 或 `空格` | 点击按钮 |

- 三条车道（左 / 中 / 右），角色自动向前奔跑；
- 橙白条纹**路障**可以跳过，餐车 / 货车必须变道躲避；
- 金色**能量币**：跑到所在车道即可收集，跳上路障上方的币弧有额外奖励；
- 速度随距离轻微提升（有上限，保证可玩）；
- 撞上障碍则本次冲刺提前结束；跑满 1000m 冲过终点拱门进入结算；
- 结算卡展示用时、能量币、躲避障碍数与 S/A/B/C 评级，最佳用时保存在浏览器 localStorage。

## 三段赛道如何变化

| 距离 | 阶段 | 视觉与场景 |
| --- | --- | --- |
| 0–300m | 海滨公路 | 天空蓝 + 沙滩米 + 海盐蓝；两侧是海面（波光、帆船）与沙滩（椰子树、遮阳伞），白色护栏，远处岛丘与灯塔 |
| 300–700m | 城市高架 | 水泥灰 + 路灯黄 + 车道白；金属护栏、暖黄路灯、头顶钢架天桥（绿色路牌「滨海大道」）、护栏外对向车辆剪影、远处城市天际线 |
| 700–1000m | 灯牌街区 | 夜幕降临：月亮与星空，霓虹广告牌（海风茶饮 / 夜市烧鸟 / 星光旅社）闪烁，跨街灯串，路面霓虹反光，速度线增强 |

阶段切换时天空、地面、路面、雾色等 11 组颜色在 270–330m 与 670–730m 两段区间内连续插值过渡（不是硬切），场景实体（椰子树→路灯→广告牌）按各自的世界坐标淡入淡出，并有全屏横幅提示。300m 与 700m 处的进度条刻度和阶段徽章同步变化。

## 部署

`dist/` 是可直接部署到任意静态 CDN / 虚拟主机的纯静态目录（仅 3 个文件，相对路径引用）：

```bash
# GitHub Pages（本项目采用）
# 将 dist/ 内容推送到仓库根分支，仓库 Settings → Pages 选择该分支即可

# Vercel
vercel deploy dist --prod --yes

# Netlify
netlify deploy --dir dist --prod
```

## 继续优化的方向

- **赛道弯曲**：把视觉弯道从「屏幕空间偏移」升级为逐段累计曲率，支持更夸张的 S 弯与上下坡；
- **障碍多样性**：加入移动障碍（横穿的行人 / 清扫车）、连续窄缝、需要下蹲的横杆；
- **道具系统**：磁铁吸附能量币、护盾抵挡一次撞击、加速带；
- **音效与音乐**：用 WebAudio 合成节奏背景乐，并随阶段切换曲风；
- **成绩体系**：本地排行榜、每日挑战种子（seed）赛道、分享成绩卡片图；
- **性能**：把高频更新的实体池换成单个 `<canvas>` 混合渲染，进一步降低移动端开销；
- **无障碍**：补齐 `prefers-reduced-motion` 下的完整降级与色弱友好的障碍配色。
